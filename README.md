# HR Kit

مرجع داخلي لموظفي الموارد البشرية للنماذج والخطابات والملفات.

## التشغيل

```bash
npm install
npm run dev
```

## قاعدة البيانات

المشروع يحتوي على migrations. في حال كانت قاعدة D1 موجودة مسبقًا، طبّق migrations على القاعدة البعيدة:

```bash
npm run db:remote
```

النسخة الحالية تحتوي أيضًا على فحص تلقائي للحقول الجديدة عند استخدام لوحة الإدارة، لكن يفضّل دائمًا تطبيق الـmigration رسميًا قبل النشر.

## الإدارة

افتح `/admin.html` وسجّل الدخول باستخدام قيمة `ADMIN_PASSWORD` في إعدادات Cloudflare.

من لوحة الإدارة يمكنك إدارة الملفات والأقسام وإخفائها وأرشفتها وتحديد الملفات المميزة.

## الأيقونات

عند إنشاء أو تعديل قسم، اختر الأيقونة من مجموعة الأيقونات الجاهزة بدل كتابة رمز يدويًا.
